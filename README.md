# abjas2121. Для чего нужен JavaScript?
Для создания интерактивности на веб-страницах: реакции на действия пользователя, изменения содержимого и стилей без перезагрузки страницы.
2. Как подключить внешний файл script.js?
С помощью тега <script src="script.js"></script> перед закрывающим тегом </body>.
3. Что такое DOM?
Объектная модель документа (Document Object Model) — представление HTML-страницы в виде дерева объектов, которыми можно управлять с помощью JavaScript.
4. Для чего нужен querySelector()?
Для поиска и получения первого элемента на странице по указанному CSS-селектору.
5. Что такое событие click?
Сигнал браузера о том, что пользователь нажал (кликнул) на элемент страницы.
6. Что делает addEventListener()?
Назначает функцию-обработчик, которая будет выполняться при наступлении указанного события в элементе.
7. Зачем используется textContent?
Для чтения или изменения текстового содержимого внутри HTML-элемента.
8. Почему сообщение появляется только после нажатия?
Потому что код внутри addEventListener() срабатывает не при загрузке страницы, а только в момент возникновения события click.
9. Чем отличаются селекторы #buy и .product?
#buy выбирает элемент по уникальному идентификатору (id="buy"), а .product — по классу (class="product").
